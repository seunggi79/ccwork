# 보더 · 라운드 · 섀도우

전체 맥락은 [`README.md`](./README.md) 참고. 컬러 값(구조적 보더=검정, 보조 구분선=옅은 회색)은
[`colors.md`](./colors.md) 참고.

## 토큰

| 항목       | 현재 값                                                                    | 권장 값 (YEEZY) | 비고                                                                                                                                                                                                  |
| ---------- | -------------------------------------------------------------------------- | --------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `--radius` | `0.75rem`                                                                  | `0`             | 하드엣지. 현재 코드가 `--radius` 토큰을 실제로 참조하지 않고 `rounded-xl`/`2xl`/`3xl`을 직접 쓰고 있는데, 리스타일링 시에는 이런 클래스들을 전부 `rounded-none`(=라운드 클래스 제거)으로 바꿔야 한다. |
| 보더 두께  | 다양 (`border`, 커스텀 없음)                                               | `1px` 모노라인  | 구조적 보더는 검정, 보조 구분선은 옅은 회색 ([`colors.md`](./colors.md) 참고).                                                                                                                        |
| 섀도우     | arbitrary 값 3곳 (`Layout` 헤더, `NoteItem` 선택/hover, `NoteEditor` 카드) | **전부 제거**   | `shadow-*` 클래스를 사용하지 않는다. 깊이는 여백과 보더만으로 표현한다.                                                                                                                               |

## Do / Don't

- **DO** 모든 코너는 각지게(`rounded-none`, radius 0).
- **DO** 1px 모노라인 보더로 구조를 정의한다 (구조적 보더=검정, 보조 구분선=옅은 회색).
- **DO** 깊이는 여백과 보더만으로 표현한다.
- **DON'T** `rounded-xl`/`2xl`/`3xl` 등 라운드 클래스를 쓰지 않는다.
- **DON'T** 보더 대신 배경색 채움으로 영역을 구분하지 않는다.
- **DON'T** `shadow-*` 클래스(드롭섀도우, 이너섀도우)를 쓰지 않는다.
- **DON'T** 블러 처리된 스크림을 쓰지 않는다 — 모달 등은 플랫한 반투명(~85% 불투명 흰색)만.
