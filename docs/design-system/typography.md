## 토큰

| 토큰             | 현재 값                                        | 권장 값 (YEEZY)                                                   | 비고                                                                                                                                                                                                           |
| ---------------- | ---------------------------------------------- | ----------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `--font-sans`    | `'Pretendard Variable', system-ui, sans-serif` | `'IBM Plex Mono', 'D2Coding', 'Noto Sans Mono CJK KR', monospace` | 라틴/숫자는 IBM Plex Mono, 한글은 한글 지원 모노스페이스 폴백. **최종 폰트는 TBD** — 실제 적용 전 한글 렌더링 품질을 확인하고 확정할 것.                                                                       |
| `--font-display` | `'Boogaloo', sans-serif`                       | **토큰 자체를 삭제**                                              | 장식적 display 폰트는 "단일 서체 · 딘담 보이스" 원칙과 정면으로 상충한다. `Layout.tsx`의 인라인 `style={{ fontFamily: 'Boogaloo, sans-serif' }}`도 함께 제거 대상 (문서화 범위 밖, 후속 스타일 작업에서 처리). |

**사이즈 스케일**: 10–22px 범위에서 촘촘하게. 굵기(`font-bold` 등)나 사이즈 다양성으로 위계를
만들지 않고, 배치와 여백으로 위계를 만든다.

**자간(letter-spacing)**: 대문자 라틴 요소에 `0.08em`–`0.16em`의 넓은 자간을 준다. 한글
라벨에도 리듬을 맞추기 위해 넓은 자간을 적용할 수 있다 (`tracking-widest` — 이미
`NoteList`/`NoteEditor`의 eyebrow 라벨에 쓰이고 있는 패턴과 일치).

## Do / Don't

- **DO** 모노스페이스 서체 하나만 쓴다 (`--font-sans` 재정의값, 위 토큰 표 참고).
- **DO** 위계는 위치와 여백으로 만든다. 사이즈/굵기 종류를 늘리지 않는다.
- **DO** 한글 UI 텍스트는 원문 그대로(대문자 변환 없음), 자간만 넓게 유지한다.
- **DON'T** 장식적 display 폰트(현재의 Boogaloo 등)를 쓰지 않는다.
- **DON'T** 라틴 문자가 아닌데 대문자 변환을 시도하지 않는다 (한글에는 의미 없음).
