# 컬러

전체 맥락은 [`README.md`](./README.md) 참고. 여기서는 컬러 토큰 값과 사용 규칙만 다룬다.

## 토큰

`src/index.css`의 `@theme` 블록에 정의된 실제 변수 이름 기준. **아직 코드에는 적용되지
않았다** — 적용 시 아래 "권장 값"을 해당 변수에 대입한다.

| 토큰                       | 현재 값                                  | 권장 값 (YEEZY)                                                                   | 비고                                                                                                                                                                                                                                                                                                  |
| -------------------------- | ---------------------------------------- | --------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `--color-background`       | `hsl(0 0% 94%)` (연회색)                 | `#FFFFFF`                                                                         | 순백 캔버스. 페이지 배경에 회색 톤을 두지 않는다.                                                                                                                                                                                                                                                     |
| `--color-card`             | `hsl(0 0% 100%)`                         | `#FFFFFF`                                                                         | YEEZY는 카드/컨테이너 개념이 없다 (제품이 배경 위에 그대로 뜬다). `background`와 `card`가 같은 값이 되면서, 카드에 별도 배경색으로 구분을 주던 관행 자체가 사라진다 — 구분은 hairline 보더로만 한다.                                                                                                  |
| `--color-foreground`       | `hsl(220 35% 14%)` (남색 기가 도는 다크) | `#000000`                                                                         | 순흑. 색조(hue)가 섞인 다크 그레이 대신 완전한 검정.                                                                                                                                                                                                                                                  |
| `--color-muted`            | `hsl(0 0% 90%)`                          | `#EDEDED`                                                                         | hairline 배경/보조 버튼 배경 등 최소한의 회색 용도로만.                                                                                                                                                                                                                                               |
| `--color-muted-foreground` | `hsl(0 0% 42%)`                          | `#767676`                                                                         | 보조 텍스트/라벨. 원본 그레이 스케일의 상한값.                                                                                                                                                                                                                                                        |
| `--color-border`           | `hsl(0 0% 88%)`                          | **용도별 이원화** — 구조적 보더: `#000000`(1px), 보조/약한 구분선: `#EDEDED`(1px) | 지금은 단일 회색 토큰이지만, YEEZY는 "보더가 구조를 정의"하므로 카드 외곽선처럼 구조를 나타내는 보더는 검정, `NoteEditor` 제목/본문 사이 구분선 같은 보조 구분선은 옅은 회색으로 구분해야 한다. 토큰을 두 개로 쪼갤지, 컴포넌트별로 `border-black`/`border-[#ededed]`를 직접 쓸지는 적용 시점에 결정. |
| `--color-destructive`      | `hsl(0 84% 60%)`                         | `hsl(0 84% 60%)` (유지)                                                           | **원본 브리프에 없는 예외 토큰.** 완전 모노크롬 원칙에서 벗어나지만, 삭제 등 비가역 액션 경고 목적으로 유지한다 ([`README.md`](./README.md)의 Substitutions & caveats 참고). 값 자체는 바꿀 필요 없음.                                                                                                |

## Do / Don't

- **DO** 배경은 `#FFFFFF`, 전경/텍스트/구조적 보더는 `#000000`만 쓴다.
- **DO** 회색(`#767676`~`#EDEDED`)은 hairline과 비활성(disabled) 상태에만 쓴다.
- **DO** 삭제 등 비가역 액션에는 `--color-destructive`(red)를 예외적으로 허용한다.
- **DON'T** 브랜드 포인트 컬러, 정보성 강조색, 그라디언트를 추가하지 않는다.
- **DON'T** destructive 외의 상태(성공, 경고, 정보)를 색으로 구분하지 않는다 — 텍스트와
  반전(inversion)으로 구분한다.
