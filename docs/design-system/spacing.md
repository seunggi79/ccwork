# 스페이싱

전체 맥락은 [`README.md`](./README.md) 참고.

## 토큰

별도의 커스텀 스페이싱 토큰을 추가하지 않는다. Tailwind v4의 기본 스페이싱 스케일(0.25rem=4px
단위)에서 **8px의 배수가 되는 짝수 클래스만 사용**하는 것을 규칙으로 삼는다
(`p-2`=8px, `p-4`=16px, `p-6`=24px, `p-8`=32px, `p-12`=48px 등).

- 현재 코드에서 8px 배수를 벗어나는 값(`mt-1.5`=6px 등)은 다음 리스타일링 시 가장 가까운 8px
  배수(`mt-2`=8px)로 정리 대상.

## Do / Don't

- **DO** 8px 배수(`p-2`, `p-4`, `p-6`, `p-8`, `p-12`…)만 쓴다.
- **DO** 여백을 넉넉하게 줘서 요소가 "숨 쉬게" 만든다.
- **DON'T** 8px 배수를 벗어나는 임의 값(`mt-1.5` 등)을 쓰지 않는다.
