# 콘텐츠 보이스

전체 맥락과 한국어 유지 결정의 배경은 [`README.md`](./README.md)의 Substitutions & caveats
섹션 참고.

## Do / Don't

- **DO** 한글 UI 텍스트를 그대로 유지한다 (CLAUDE.md 규칙).
- **DO** 신규로 노출되는 문구는 과장된 수식어 없이 담백하고 사무적으로 쓴다 (anti-marketing,
  deadpan 톤 — 기존 `console.error('제목을 입력해주세요')` 같은 문구의 담백한 어투를 화면 노출
  문구에도 적용).
- **DON'T** 이모지, 느낌표, 설득형 카피("멋진 노트를 만들어보세요!" 등)를 쓰지 않는다.
- **DON'T** UI 텍스트를 영어로 바꾸지 않는다 (원본 브랜드 보이스는 참고만 하고, 언어는
  CLAUDE.md 규칙을 따른다).
