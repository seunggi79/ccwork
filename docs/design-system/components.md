# 컴포넌트 패턴 & 아이콘

전체 맥락은 [`README.md`](./README.md) 참고. 색/보더/모션 값은 각각
[`colors.md`](./colors.md) / [`borders-shadows.md`](./borders-shadows.md) /
[`motion.md`](./motion.md) 참고.

이 앱에 실제로 존재하거나 계획된 것만 다룬다. 원본 브리프의 스토어프론트 전용 컴포넌트
(`ProductTile`, `SizeSelector`, `DotPagination`, 체크아웃 흐름 등)는 **Out of Scope** — 해당
없음.

## 아이콘

- **DO** `+`(메뉴/추가/펼침), `×`(닫기), `‹`/`›`(뒤로/다음) 같은 모노스페이스 유니코드 글리프를
  텍스트처럼 렌더링한다 — 아이콘이 곧 타이포그래피의 일부가 되게 한다.
- **DON'T** 아이콘 폰트, SVG 스프라이트, 이모지, 다색/채워진 아이콘을 쓰지 않는다.

## Button (저장 / 취소 / 새 노트)

- **DO** 주요 액션(저장, 새 노트)은 솔리드 블랙 배경 + 흰 텍스트, hover 시 `#111`로만 살짝
  어둡게.
- **DO** 보조 액션(취소)은 아웃라인/보더만 있는 형태 또는 회색 배경(`--color-muted`).
- **DON'T** 버튼에 그림자나 라운드를 주지 않는다. 각지고 평평하게.

## IconButton (삭제 버튼 등)

- **DO** 텍스트 라벨("삭제")과 동일한 시각적 무게로, hover 시 destructive 색으로만 전환.
- **DON'T** 원형 배경이나 아이콘 전용 컨테이너(circle button) 스타일을 쓰지 않는다.

## Input / Textarea (제목·내용 입력)

- **DO** hairline 보더 또는 밑줄(underline)로 입력 영역을 표시하고, 포커스 시 보더를 검정으로
  강조(반전 원칙과 일치).
- **DON'T** 채워진 배경(filled input), 라운드 보더, 포커스 시 컬러 아웃라인(box-shadow ring)을
  쓰지 않는다.

## StatusLabel (저장 중 / 오류 등)

- **DO** 상태를 그대로 평문 텍스트로 보여준다 (`저장 중...`, `실패` 등 — 원본의 `ADDING`,
  `SOLD OUT` 패턴과 동일한 정신).
- **DON'T** 상태를 뱃지나 색상으로 표시하지 않는다 (destructive 예외 제외).

## Modal (향후 삭제 확인 다이얼로그 등)

- **DO** 스크림은 블러 없는 플랫 반투명 흰색(~85%), 모달 자체는 hairline 사각형 + 흰 배경,
  radius 0.
- **DON'T** 블러 배경, 그림자로 뜨는 카드, 둥근 모서리를 쓰지 않는다.

## 태그 칩 (`docs/features/tag/spec-fixed.md` 연계)

태그 기능 스펙 문서에서 칩 형태의 태그 UI(추가/삭제 버튼 포함)가 이미 계획되어 있다. 이 디자인
시스템 적용 시 다음 방향을 따른다 — 두 문서가 서로 어긋나지 않도록 명시:

- **DO** 태그 칩은 pill(완전 둥근 모서리)이 아니라 **hairline 사각형 + `×` 글리프**로 구현한다.
- **DO** 칩 배경은 흰색 또는 `--color-muted`, 텍스트는 검정, 보더는 1px.
- **DON'T** 칩마다 다른 색을 랜덤 배정하거나 `rounded-full` pill 형태로 만들지 않는다.
